# Archived source

This directory preserves retired analyses and implementations replaced by the supported workflows. See the repository README for current entry points.

`move_manifest.csv` records relocations, reasons, replacement paths and original SHA-256 checksums. Archived investigation notes remain local and ignored. Some files were relocated more than once; follow successive destination/source entries to find the current path. Numerical outputs and audit files under ignored generated-data paths remain local.

Retired implementations remain local and are excluded from source distributions. Active tests use compact reference tables under `tests/fixtures/`; the supported workflows and tests are independent of this archive.
